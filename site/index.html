Synchronisation Google Tasks ↔ Rappels iCloud

Une application TypeScript pour router automatiquement les tâches entre Google Tasks et Rappels iOS selon vos listes Live Session, Laurent.janolin et Tâches domestiques.

Depuis iOS

Les rappels de Live Session deviennent des tâches Google dans Laurent.janolin avec le préfixe iOS. Les autres rappels vont vers Tâches domestiques.

Depuis Google Tasks

Les tâches de Tâches domestiques sont envoyées vers Rappels. Dans Laurent.janolin, seules les tâches commençant par iOS sont envoyées.

Listes intelligentes

Le suffixe - Maison cible la liste Rappels correspondante. En cas d'erreur de nom, la liste la plus proche est choisie ou la liste par défaut est utilisée.

Démarrage

npm install
export ICLOUD_USERNAME="votre-identifiant-icloud@example.com"
export ICLOUD_APP_PASSWORD="xxxx-xxxx-xxxx-xxxx"
DRY_RUN=true npm run sync
